# VIN Decoder

Single Page Application for decoding Vehicle Identification Numbers (VIN) using the NHTSA vPIC API.

## Live Demo

[Open deployed app](https://Akerman048.github.io/vin-decoder/)

## Features

- Decode VIN using NHTSA vPIC API
- VIN input validation
- Display decoded vehicle data
- Show API message and error-related fields
- Store and reuse the last 3 decoded VINs
- Browse all available vehicle variables
- Open a details page for a specific variable
- Responsive UI built with React + Tailwind CSS

## Tech Stack

- React
- TypeScript
- Vite
- React Router
- Tailwind CSS
